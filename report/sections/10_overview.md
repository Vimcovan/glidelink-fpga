# 第一部分  作品概述

## 1.1 功能与特性

本作品是一条基于FPGA的实时无线图像传输系统。发射端把USB摄像头、预设视频或图像裁成256×256彩色图像，由PL中的DeepJSCC-Q[2]编码器直接映射为32,768个64QAM符号，经自研OFDM物理层和AD9361发射；接收端完成同步与均衡后，把连续I/Q软符号送入PL中的解码器重建图像，在屏幕上实时显示。主要特性：

- 30 fps实时传输，编码、空口、解码全部在PL中完成，PL内端到端时延约67.5 ms；
- 信道变差时画质平缓下降，没有悬崖效应；
- 内置同物理层、同符号数的SSCC基线（JPEG + LDPC），可在触摸屏上一键切换对比，并实时调节TX衰减；
- 触摸屏显示PSNR、时延、四级均衡星座图、信道三维图（Mali-400 GPU渲染）等链路状态；
- 上电约1分钟自动建立链路，无需上位机。

## 1.2 应用领域

DeepJSCC[1]的画质随信道质量平缓变化，不需要根据信道预先选择压缩率和码率，适合信道多变、对实时性要求高、允许画质随距离逐渐降低的图像传输场景：

- 无人机、机器人和车辆的实时图传：移动中信道快速变化，传统方案在链路边缘会突然黑屏，本方案仍能输出可辨认的画面；
- 应急通信与野外监测：链路质量差、无法重传时，仍能持续得到图像；
- 低功耗物联网视觉终端：编码器是固定结构的流水线，适合在FPGA或专用芯片上以低时延实现。

本作品采用标准的OFDM物理层与QAM星座，DeepJSCC-Q可以替换现有数字图传系统的信源与信道编码部分，物理层与射频前端无需改动。当前系统的局限是图像尺寸固定为256×256，模型只在一个SNR下训练。

## 1.3 主要技术特点

1. 面向FPGA的神经网络改造：编码器在保持每幅图32,768个信道符号不变的前提下，主通道数从256减为32、下采样倍数从16减为4；解码器采用与编码器不对称的浅层结构（线性3×3卷积、4个PWL残差块、两级3×3亚像素上采样），与编码器联合训练，乘加量只有对称结构解码器的1/6，10 dB下PSNR差在0.1 dB以内。整个网络的乘加量和参数量分别降为原网络的约1/102和1/177；W8A12整数量化损失不超过0.03 dB。
2. 逐层流水的神经网络硬件：卷积引擎、行缓存、GDN、PWL等均为手写的参数化RTL模块，67个卷积算子映射为64个独立卷积引擎；每层按帧率预算选择最小并行度，权重ROM按尺寸在三种组织方式中选择，激活缓存迁入URAM，全部存储放在片上。
3. 面向长帧软符号的OFDM接收机：按晶振标称偏差的最坏情况设计二阶SFO跟踪与CPE补偿，接收端不做星座判决；PN扰码消除神经网络输出相关性带来的PAPR升高。

## 1.5 主要创新点

1. DeepJSCC-Q编码器、解码器与OFDM物理层全部在PL中实现，经真实空口30 fps实时传输。
2. 与编码器联合训练的非对称浅层解码器：非线性集中在潜变量分辨率上，上采样用3×3亚像素卷积，解码器乘加量降为对称结构的1/6、DSP降为1/6。
3. 逐层流水卷积引擎配合按层并行度与三种权重ROM组织方式，卷积工作量是已发表FPGA实现[3]的5.2倍，编码器DSP只用其15 %。
4. 面向长帧软符号的OFDM接收：二阶SFO跟踪、CPE补偿与PN扰码。
5. 同物理层、同符号数的SSCC基线实测对比：信道码为802.11n LDPC，编译码器自行设计，不用BRAM和DSP。

## 1.6 设计流程

设计流程见图1-1。首先确定神经网络与物理层之间的接口约定（每帧32,768个{Q, I}符号，AXI-Stream，2.1.5节），之后两条线并行推进，各自验证后在接口处直接对接：

1. 神经网络：按期刊版DeepJSCC-Q实现并训练浮点模型 → 设计浅层解码器并与编码器联合训练 → W8A12整数量化，建立整数参考模型 → 编写并仿真各子模块的RTL，逐个与整数参考模型做逐比特比对 → 按帧率和片上存储预算规划各层并行度与存储映射 → 由脚本完成顶层例化、参数填写与连线 → 整网与整数参考模型逐比特仿真比对，并完成250 MHz综合与时序收敛；
2. 物理层与射频：OFDM收发算法仿真，确定帧检测、定时门限与SFO跟踪环参数 → RTL编写与仿真 → AD9361接口与校准 → 单板环回测试 → 两板空口测试；
3. 系统集成：按接口约定对接编解码器与物理层，加入PS软件、GUI与SSCC基线，最后进行空口实测。
